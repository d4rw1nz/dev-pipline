# 门禁与 Harness

这里规定项目应建立的检查机制，不提供中央服务。init/adopt 结合真实语言、构建和风险实现项目自己的检查脚本，再接入 Makefile 与 CI。尚未实现并运行时，只能写“待建立”。

先按 [workflow 的任务类型与完成条件](workflow.md) 选择检查，门禁不另设一套完成标准。`transition done` 在 Issue 内记录适用检查与依据；不适用不等于通过。仅核实该任务所需事实，不强制每项任务具备所有类别的文档、代码测试和复审身份。验证材料按 [保存规则](documentation.md#验证材料的保存) 处理，不要求 evidence 目录、独立验证报告或原始输出文件。

## 值得阻断的条件

| 位置 | 阻断条件 | 证据与处理 |
| --- | --- | --- |
| 开始实现 | 验收缺失、影响范围不清、来源冲突、关键产品选择未知 | 落地需求与稳定验收编号，说明来源版本和可执行范围 |
| 架构或接口调整 | 相关职责、调用方、状态归属、历史原因未核实 | 当前结构、Git 历史、关键调用分析；目标、理由、删除对象与首个验证点 |
| 正式代码交付复审（不含诊断性审查） | 必需检查失败或未执行、结果针对旧代码或错误平台 | 执行时核对原始输出，记录实际命令、退出码、必要环境和输入版本；修复后重测 |
| 正式代码验收 | 验收缺证据、关键问题未解决、必需的交叉复审缺失或不独立 | 验收到测试的映射、复审方式与版本、适用时的独立复审身份、发现的逐项处置 |
| 关闭任务 | 文档冲突、重要长期反馈未落实、未做经验判断 | 更新需求与索引，记录反思与沉淀落点，或说明没有新增经验 |
| 外部同步与发布 | 远端版本冲突、连接未验证、缺具体授权 | 已验证来源配置、同步基线与实际结果；本地完成不能推断远端完成 |

不得通过删除断言、修改需求迎合实现、隐藏失败、排除业务文件或不断重试制造通过。已有无关失败需单独记录并举证，不能擅自降低项目既有强制要求。

## 提醒而非默认阻断

80% 是单测行覆盖率目标；低于目标或未测量须解释范围和风险，项目明确规定硬门槛时才按门槛阻断。经验条目数量、文档篇幅、提交数和文件行数不是质量证明。小改可以使用简短证据，不强制完整报告，也不能跳过关键共享行为。不因无关模块陈旧扩大为全仓重构。

## 优先实现的机器检查

1. Issue 与来源复合身份唯一、状态合法、验收项可追踪；冲突和未解决阻塞不能被完成状态覆盖。
2. 本任务适用的需求、研究、计划、结果或复审依据真实存在，可以是已有文档、Issue 内的记录或 CI 运行结果；相对链接、索引有效。不要求每类依据独立成文件，空文件或匹配标题不能证明内容合格。
3. 验证绑定提交及未提交差异，必要时计算相关输入摘要；包含代码、测试、需求、构建和检查配置，能识别新增与删除。相关输入变化使原结果失效，不能只改摘要恢复有效性。
4. 检查入口执行真实命令并读取退出码与必要环境，失败传播非零；计数和覆盖率从实际工具输出解析，不接受 agent 自填数字就通过。输出可在内存或临时目录处理，只将必要结果记入 Issue，不自动归档原始输出或另存报告。
5. 已确认的模块依赖、接口边界和状态规则，采用语言适用的 lint、类型、结构或行为测试；不用简单字符串匹配伪装语义检查。
6. 正式代码验收时记录复审方式；按 quality 确需交叉复审时，复审者与实现者不同。复审对应当前版本，发现有修正或驳回依据；不能只勾完成，也不能把不适用的交叉复审列为缺失。
7. 长期反馈有适用范围、依据和落点；过时规则有替代关系，闭环要求判断沉淀价值，不要求凑规则数量。

机器检查无法证明需求正确、测试充分或评审独立思考，按 quality 判断是否需要独立复审补充。可填写的 JSON、脚本返回零或 agent 自述不是不可伪造的审计证据。

输入与输出分开：测试日志、复审报告、Issue 执行阶段和刚写入的通过记录是输出，不能把它们纳入输入摘要造成自我失效。需求文件中的正文与验收条件，以及 Issue 中的需求版本引用、任务目标、授权范围和检查策略都属于输入，按字段或独立文件追踪；不能简单排除整个 Issue 来绕过要求变化。提交号与完整 diff 用于定位现场，证据有效性按已声明、经复审核实的实际输入判断。

## 环境与反馈

Make 提供可发现入口，CI 复用相同检查。错误消息给出具体失败条件和修正方向。隔离测试数据、端口、缓存和实例；并发明确所有权，必要时用 worktree，不动日常服务或真实凭据。按问题提供结构化日志、截图、性能和请求关联信息；先复现再修复和对比。平台与 UI 行为不能只由单测证明。

输入变化后只重跑受影响范围，但需解释其他证据为何仍适用。定期维护只在已授权范围执行，更新原规则而非累积同义规则。
